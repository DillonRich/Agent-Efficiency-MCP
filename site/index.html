How it works

  1. Install the MCP and put your DeepSeek / OpenAI / Anthropic key in env.
  2. Run npx agent-efficiency-mcp init (PRIORITY 0 rules + MCP).
  3. Prompt as usual — review the blueprint — type GO.

Built for serious vibe coders who already pay for an IDE model and will not add another monthly SaaS fee.

Install

git clone https://github.com/Agent-Efficiency-MCP/Agent-Efficiency-MCP.git
cd Agent-Efficiency-MCP
npm install && cp .env.example .env
# add your API key
npm run build
npx agent-efficiency-mcp init --project /path/to/your/app
